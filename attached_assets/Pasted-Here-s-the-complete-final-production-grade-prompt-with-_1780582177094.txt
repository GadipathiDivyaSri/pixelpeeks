# 🪄 PixelPeek — Full Build Prompt (v2 · Production-Grade)

> Build **PixelPeek**, a playful, secure steganography studio web app where users hide secret messages inside images, audio, and video files, decode them back out, and run analysis to detect hidden payloads. **Every feature must work end-to-end with verified correct outputs.** The vibe is **cute, colorful, and tactile** — like a clever puzzle game, not a dark forensic tool.

## 🔐 Security Requirements (non-negotiable)

1. **Auth**
   - bcrypt password hashing (`$2b$` hashes only, never plain MD5/SHA1)
   - JWT signed with `JWT_SECRET` (≥64-char hex, stored in `.env`, never hardcoded)
   - Access token: 1-day expiry, sent as httpOnly cookie **and** Bearer header
   - Email normalized to lowercase, uniqueness enforced via MongoDB unique index
   - Min password length 6, validated server-side via Pydantic
   - Brute-force protection: **5 failed logins in 15 min → account lockout** (track by IP+email in `login_attempts` collection)
   - Logout clears cookies server-side

2. **Payload encryption**
   - When user provides a passphrase, derive a 256-bit key via **PBKDF2-HMAC-SHA256 (200k iterations)** + random 16-byte salt
   - Encrypt payload with **AES-256-GCM** (random 12-byte nonce, auth tag)
   - Without the right key, decoding returns *"Wrong key or no hidden message."* — never leaks partial bytes
   - When no passphrase given, use XOR-key fallback OR no obfuscation (still works, less secure)

3. **CORS & cookies**
   - Explicit `FRONTEND_URL` allowed origin (no `"*"` with credentials)
   - `secure=False` only in preview; `secure=True` in production
   - `SameSite=Lax`

4. **Input validation & limits**
   - Max upload size 50 MB per file (FastAPI middleware)
   - Reject files whose declared MIME doesn't match detected carrier
   - Sanitize filenames before echoing in `Content-Disposition`
   - Never leak MongoDB `_id` in responses (project `{_id: 0}` or convert to string)

5. **Env vars only** — no hardcoded secrets, no hardcoded URLs. Read from `.env`: `MONGO_URL`, `DB_NAME`, `JWT_SECRET`, `ADMIN_EMAIL`, `ADMIN_PASSWORD`, `FRONTEND_URL`.

## 📐 Functionality — Encode / Decode / Peek

### 1. **Encode** (`/encode`)

Tabbed UI: **Image · Audio · Video**. Auto-detect carrier on drop.

| Carrier | Formats | Algorithm |
|---|---|---|
| **Image** | PNG, BMP, JPG, JPEG, WEBP | LSB embedding in R/G/B channels. Output: PNG (lossless). |
| **Audio** | WAV (16-bit PCM mono/stereo) | LSB embedding in int16 samples. Output: WAV. |
| **Video** | MP4, MOV, WEBM, AVI, MKV | Byte-tail append with magic markers `PXP1 + 4-byte-length + payload + 1PXP`. Playback unaffected. |

- Optional passphrase → AES-256-GCM encrypt payload before embedding
- Capacity check: if message larger than available bits, return `400` with byte-budget hint
- Return file as download (`Content-Disposition: attachment`)
- Show inline preview (img/audio/video) + big **Download** button

`POST /api/encode` — multipart: `file`, `message`, `key` (optional)

### 2. **Decode** (`/decode`)

Same 3 tabs. Upload + key → reveal hidden message.

- Read LSBs (or tail payload for video), decrypt with key
- Wrong key / no payload → friendly 400: *"No hidden message found (or wrong key)."*
- Success → **spring-scale reveal** of recovered text + "Copy to clipboard" button
- **Correctness rule**: encoding then decoding the same file+key MUST return the exact original message — verified by automated tests

`POST /api/decode` — multipart: `file`, `key` (optional)

### 3. **Peek** (`/peek`) — Steganalysis

**Classical 5-D feature pipeline + SVM (RBF kernel)** — no deep learning.

**Features**:
1. **Entropy** — Shannon entropy of byte distribution (0–8)
2. **LSB ratio** — mean of LSB plane (stego ≈ 0.5)
3. **LSB deviation** — `|lsb_ratio − 0.5|` (stego ≈ 0)
4. **Chi-square** — Pairs-of-Values test, normalized
5. **Block-LSB-stdev** — stddev of LSB ratio across 64-sample blocks (clean = variable, stego = uniform)

**Classifier**: `Pipeline([StandardScaler, SVC(kernel='rbf', probability=True)])` trained on **1200 synthetic clean + 1200 synthetic stego** vectors at startup.

**Verdicts**: `prob ≥ 0.80` → **STEGO** (red) · `≥ 0.55` → **SUSPECT** (yellow) · else **CLEAN** (mint)

**Per-media**:
- Image: flatten RGB → features
- Audio: take low byte of int16 samples → features
- Video: sample up to 24 frames via OpenCV, average per-frame features

**Correctness rules** (must pass tests):
- Clean natural photo → **CLEAN** with `prob < 0.55`
- Image with full LSB embedding → **STEGO** with `prob > 0.80`
- Clean WAV (sine wave) → **CLEAN**
- LSB-stego WAV → **STEGO**

**UI**: circular SVG probability gauge (color-coded), big verdict stamp, blurb, and 5 horizontal feature bars with raw values.

`POST /api/detect` — multipart: `file`
